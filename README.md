# ТТТ: Тунеядзец тутэйшы торгаш

Игра в духе GTA, но в Беларуси. Вид сверху, 2D.
Игра вне политики: никаких политических тем и отсылок.

## Название по языкам

| Язык | Название |
|---|---|
| Белорусский | ТТТ: Тунеядзец тутэйшы торгаш |
| Русский | ТТТ: Тунеядец местный торгаш |
| English | TTT: Loafer, Local, Trader |

Третье «Т» — «торгаш». Альтернатива: «темщик».

## Суть

Главный герой — тунеядец без работы 5/2. Он местный (тутэйшы).
В начале игра спрашивает у игрока: «Как тебя зовут?» — и зовёт героя этим именем.
Чтобы зарабатывать, герой подрабатывает законными делами по Минску.

## Сеттинг

Центр Минска: автовокзал, проспект Независимости, рынок Комаровка.

## Прототип (playable)

- Код: `ttt/game/index.html` (один файл, canvas, без сборки).
- Играть: `https://ttt.ladyka.by` (тоннель на ноутбук, порт 24000).
- Управление: WASD/стрелки — идти, E — действие рядом, N — газета с вакансиями.
- Все механики прототипа — в `mvp.md`.
